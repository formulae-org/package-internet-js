# internet-js

Internet package for [Fōrmulæ](https://formulae.org) — the visual environment for **computing**, **composing**, and **conversing** with tree-structured expressions.

This repository contains the source code for the **internet package**. It contains functionality to manage internet resources.

> Part of the [formulae-org](https://github.com/formulae-org) organization: the [web application](https://github.com/formulae-org/formulae-js) plus one repository per package.

### Capabilities ###

* Visualizations
    * Uniform resource locator (URL) — a clickable link that opens in a new tab
